Full-Stack Architecture

From Edge Hardware to Real-Time AI Directives

1. Hardware Edge: ESP32 microcontrollers + YF-S201 Water Flow Sensors + PIR Motion Sensors.
2. Backend Core: Python FastAPI handling high-frequency WebSocket streams.
3. ML Intelligence: Isolation Forest anomaly model trained on campus baseline data.
4. Frontend Layer: Real-time admin control dashboard.
